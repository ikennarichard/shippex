A modern, feature-rich mobile application designed for efficient shipment management. Built with React Native, Expo, and TypeScript, this app delivers a seamless user experience with an intuitive interface.

## 🚀 Key Features

- **Smart Selection System**: Select all or individual shipments with clear visual feedback
- **Advanced Filtering**: Collapsible filters for efficient shipment organization
- **Grouped Lists**: Organized shipment display for better navigation
- **Modern UI/UX**: Clean, professional interface following Material Design principles
- **Cross-Platform**: Works seamlessly on both iOS and Android devices

## 💻 Development Setup

### Prerequisites

Ensure you have the following tools installed on your development machine:

- [**Bun**](https://bun.sh/docs/installation) (v1.1.3 or higher)
- [**Expo CLI**](https://docs.expo.dev/get-started/installation/)
- [**Node.js**](https://nodejs.org/) (v18 or higher)

### Installation & Setup

1. **Clone the repository**

   ```bash
   git clone https://github.com/ikennarichard/shippex.git
   cd shippex
   ```

2. **Install dependencies**

   ```bash
   bun install
   ```

3. **Start the development server**

   ```bash
   bun start
   ```

4. **Prebuild for native platforms**

   ```bash
   npx expo prebuild

   npx expo run:ios # IOS
   npx expo run:android #Android
   ```

### Development Options

**Option 1: Expo Go (Recommended)**

- Install Expo Go on your mobile device
- Scan the QR code from your terminal
- Live reload and hot reloading included

**Option 2: Native Development Build**

- Use `npx expo run:ios` or `npx expo run:android`
- Better for testing native features
- Requires Xcode (iOS) or Android Studio (Android)
